# R6 — الوسائط والمكتبة والتنزيلات والمستندات
**الهدف:** الأقسام 10 و11 و12 و13 من الوثيقة. دور كبير؛ إن انضمت جلسة إضافية فليُقسَّم إلى (مشغّل ومكتبة) و(تنزيلات ومستندات).
**تملك:** مسارات R6 في `docs/TEAM.md`.
**المهام:**
1. مشغّل فيديو وصوت داخلي مستقر (ExoPlayer عبر مكتبة موثوقة): استئناف من آخر موضع، حفظ تلقائي، السابق/التالي، قائمة المجلد، ملء الشاشة وتدوير حر، سرعة 0.5–2x، نقرتان للقفز ±10 ثوانٍ، ضغط مطول 2x، سحب للسطوع والصوت، إعادة بناء عند التعطل. زر «دوّن ملاحظة عند هذه الثانية» مرتبط بالفيديو.
2. يوتيوب: المشغّل المضمّن والمتصفح المقيّد موجودان؛ أضف استخراج **المدة الحقيقية** عبر IFrame API الرسمية (تحميل مخفي ثم `getDuration`) وخزّنها، وانشرها لـ R3 في `VideoDuration`. **ممنوع** استخراج مسارات الفيديو للتنزيل (مخالف لشروط يوتيوب)؛ البديل حفظ الرابط والتشغيل المتصل.
3. المكتبة: مجلدات متداخلة، نقل/إعادة تسمية/حذف، ترتيب طبيعي، بحث وفلاتر، ترقيم ذكي «001 - عنوان» مع إعادة ترقيم عند الإدراج دون تضارب أو فقدان. حفظ في مساحة يختارها المستخدم (SAF) أو تصدير واستعادة.
4. التنزيلات: ملفات مودل المباشرة (بجلسة الطالب)، طابور وإلغاء وإعادة محاولة وتقدم، تنزيل مجلد أو مادة، حفظ الحالة بعد الإغلاق، وفق قواعد الخدمات الأمامية.
5. المستندات: PDF أولاً ثم Word وPowerPoint وExcel والصور والنصوص؛ تكبير وبحث وتنقل وRTL ومشاركة، واستيراد من الهاتف ومن Google Drive عبر مُنتقي الملفات الرسمي.
6. عقودك: `PlaybackEvents` (لـ R5) و`VideoDuration` (لـ R3).
**القبول:** اختبارات حفظ الموضع والترقيم والتنزيلات، وتشغيل فعلي على جهاز.
